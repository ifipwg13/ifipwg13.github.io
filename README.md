# IFIP WG 1.3 website

Source for the [IFIP Working Group 1.3 website](https://ifipwg13.github.io/),
including group information, meetings, talk abstracts and presentation slides.

GitHub Pages publishes the website from the `main` branch.

Maintenance and administration are documented in the
[private operating guide](https://github.com/ifipwg13/meetings/blob/main/README.md).
